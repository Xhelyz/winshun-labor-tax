# 劳务报酬计算器（Win顺 插件）

在 Win顺 搜索框里直接算劳务报酬的个人所得税：**税前算税后**，也能**按税后反推税前**。Enter 复制数字，悬停看完整明细。

> 界面说明：Win顺 的插件结果列表由宿主绘制，插件只能提供标题、副标题、复制值和悬停明细，不能自定义配色与排版。所以本插件不带自定义界面，外观跟随 Win顺 自身风格；作者另有一个独立网页版（单文件 HTML，与插件共用同一套算法）用于需要大屏展示的场景，它不属于本插件包。

## 关键字与示例

| 输入 | 结果 |
|---|---|
| `劳务 8000` | 税前 8,000 → 税后 6,720.00，个税 1,280.00 |
| `劳务 税后 6720` | 税后 6,720 → 税前 8,000.00，个税 1,280.00 |
| `劳务 1.5万` | 按 15,000 元计算 |
| `劳务 8,000元` | 千分位、`元`、`¥`、全角数字都能识别 |
| `lw 6720 税后` | 关键字顺序不影响，`税后` 写在前后都行 |

结果固定为：税后到手、预扣个税、应纳税所得额、税前收入、预扣率与级数、换向、口径提示。第一行是当前方向最想拿到的那个数；`换向` 那一行按 Enter 直接切到反方向，按 Tab 把命令填回输入框。

为什么"能算"和"不能算"的边界是这样：

- 只输入 `劳务` 或 `劳务 税后`（没有金额）→ 列出三条可直接 Tab 填充的示例，不报错。
- 输入里没有数字（如 `劳务 abc`）→ 明确提示"没有找到金额"，不静默给示例。
- 一行里写了两个金额（如 `劳务 8000 5000`）→ 提示一次只算一笔，不猜你想算哪个。
- 同时写 `税前` 和 `税后` → 提示方向冲突。
- 金额为 0 或超过 1 亿 → 提示核对，不返回可疑数字。

## 计算口径

只算**个人所得税的预扣预缴**，按次计算。依据《国家税务总局关于发布〈个人所得税扣缴申报管理办法（试行）〉的公告》（国家税务总局公告 2018 年第 61 号）第八条及附件《个人所得税预扣率表二（居民个人劳务报酬所得预扣预缴适用）》：

1. 减除费用：每次收入不超过 4,000 元的，按 800 元计算；4,000 元以上的，按收入的 20% 计算。
2. 预扣预缴应纳税所得额 = 收入 − 减除费用（不足 0 时按 0）。
3. 应预扣预缴税额 = 应纳税所得额 × 预扣率 − 速算扣除数。
4. 预扣率表二：不超过 20,000 元为 20%（速算扣除数 0）；超过 20,000 元至 50,000 元的部分为 30%（2,000）；超过 50,000 元的部分为 40%（7,000）。

几个核对点：税前 4,000 → 税后 3,360.00；税前 25,000 → 税后 21,000.00；税前 62,500 → 税后 49,500.00；税前 100,000 → 税后 75,000.00。这三处正是档位与减除方式的分界，`tests/` 里都有断言。

**不含增值税及附加。** 个人提供劳务的增值税按小规模纳税人处理，月销售额 10 万元以下免征（财政部 税务总局公告 2023 年第 19 号，执行至 2027-12-31），适用 3% 征收率的减按 1%；附加税费还要按城建税 7%/5%/1% 分档、各地口径不一。在小额外聘劳务的常见场景里这些通常为 0，硬给一个数字反而会误导，所以这里不掺进去。真要连税一起算，请以代开发票时的完税凭证为准。

**预扣税额不等于最终税负。** 劳务报酬属于综合所得，年度汇算时按收入的 80% 并入综合所得，与工资薪金合并适用 3%–45% 超额累进税率，多退少补。插件在结果里保留这条提示。

## 运行依赖

- Win顺 0.7.0 以上（用到一次性插件的 `WS_*` 环境变量契约与 `setQuery` 效果）。
- Python 3.8 以上，只用标准库（`decimal`、`re`），无第三方包。Win顺 会自动定位 `python.exe`，找不到时卡片上会写原因并给下载链接。
- `winshun.py` 是官方 SDK（来自 `src/plugins-sdk/`），随插件一起分发，不需要安装。

## 权限

**不申请任何权限**（`"permissions": []`）。纯计算：读输入、输出结果，不读写文件、不联网、不读写剪贴板、不起子进程。

复制由用户在结果行上按 Enter 触发，走宿主的 `copy` 效果，不需要 `clipboard:write`。

## 数据位置

无。插件不写任何文件，不创建 `WS_DATA_DIR` 内容，不缓存。卸载无残留。

## 失败处理

| 情况 | 表现 |
|---|---|
| 输入无法解析 | 结果区一行红字式提示"无法计算：没有找到金额"，附正确写法示例 |
| 金额越界 | 同上，说明"金额超过 1 亿，请核对后重试" |
| 找不到 Python | Win顺 在插件卡片上写明是哪个文件、为什么，并给下载链接 |
| 查询超时 | 单次查询上限 3 秒（纯本地计算远低于此）；超时由宿主标记，连续超时按宿主的退避策略处理 |
| 插件进程异常 | stderr 进 `%LOCALAPPDATA%\WinShun\plugins.log`；本插件不打印任何诊断到 stdout，不会污染协议 |

没有网络依赖，所以不存在"依赖或网络不可用"的失败路径；`tests/sim_plugin.py` 里覆盖的是空输入、无效输入与越界这三类。

## 验证

```
python -m unittest discover -s tests -p "test_*.py"    # 22 项：算法、边界、往返、解析、清单
python tests/sim_plugin.py                             # 7 组查询 + 2 组动作，按宿主契约启动进程核对 stdout
```

`sim_plugin.py` 验证的是"脚本产出符合协议的 JSON"，**不等于**宿主内的真实往返。后者需要在 Win顺 里打开插件开关、输入关键字，看"设置 → 插件 → 高级 → 消息记录"里的请求与响应。
